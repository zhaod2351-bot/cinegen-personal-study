# CineGen 个人学习版开发交接（2026-08-14）

## 1. 用户最终目标

开发一个个人使用的 AI 动画制作网站，核心流程为：

1. 输入或导入剧本。
2. GPT 润色、分析人物/场景/道具并拆解导演计划。
3. 锁定剧本后同步资产库、镜头、导演台和故事板。
4. 使用图片生成模型制作六格故事板，并保留版本、修改和重试能力。
5. 视频模型暂不配置，保留扩展入口。

用户希望界面布局接近 AniKuku 的信息密度与工作流，但本项目保持独立自研逻辑，不复制其私有源码或绕过付费机制。

## 5. 下一项功能：网页 API 设置中心

用户刚刚批准方向，但还没有回复最终的“确认设计”。已向用户提交的设计如下：

### UI

点击左下角“系统设置”，打开完整设置弹窗，包含：

1. 大语言模型
   - 服务商 / OpenAI 兼容
   - API Base URL
   - 模型名称
   - 独立 API Key
   - 显示/隐藏
   - 测试连接
   - 保存状态
2. 图片生成模型
   - API Base URL（可与文本相同）
   - 模型名称，默认 `gpt-image-2`
   - 另一枚独立 API Key
   - 显示/隐藏
   - 测试连接
   - 保存状态
3. 视频生成模型
   - 显示“暂未配置”
   - 仅保留未来扩展入口

### 安全设计

- 密钥不得保存到浏览器 localStorage、项目 JSON、Git 或前端 bundle。
- 后端只返回掩码，例如 `sk-****8f2a`，不返回完整密钥。
- 用户选择“记住密钥”。推荐使用 Windows 当前用户绑定的 DPAPI 加密，将密文保存为本地设置文件。
- 服务启动时解密到内存。
- 提供清除密钥操作。
- 第三方中转站会看到剧本和参考图，应在 UI 中明确提示隐私风险。

### 数据流

- GPT 剧本分析使用文本 Base URL + 文本 Key + 文本模型。
- 故事板生成使用图片 Base URL + 图片 Key + 图片模型。
- 两套配置完全独立。
- 第三方响应不兼容时显示原始错误，但不得覆盖旧剧本、资产或故事板版本。

### 后端 API 建议

```text
GET    /api/settings/ai
PUT    /api/settings/ai
DELETE /api/settings/ai/text-key
DELETE /api/settings/ai/image-key
POST   /api/settings/ai/test-text
POST   /api/settings/ai/test-image
```

`GET` 仅返回 Base URL、模型名、是否已配置、密钥掩码，绝不返回密钥原文。

## 7. 实施建议

建议拆分为以下小模块：

```text
server/settings/aiSettingsStore.ts      # 设置读取、掩码和持久化接口
server/settings/windowsDpapi.ts         # Windows DPAPI 加解密适配器
server/settings/types.ts                # 文本/图片配置类型
components/AiSettingsDialog.tsx         # 设置弹窗
services/aiSettingsService.ts           # 前端 API 客户端
```

`OpenAIGateway` 当前从启动配置接收单套 `apiKey`。需要重构成独立客户端或运行时配置提供器：

```text
textClient  = { baseURL, apiKey, model }
imageClient = { baseURL, apiKey, model }
```

设置保存后，新任务应立即读取最新配置，无需重启后端。

测试至少覆盖：

- GET 设置不泄露密钥。
- 保存后返回正确掩码。
- 文本 Key 与图片 Key 不会串用。
- Base URL 能分别配置。
- 清除其中一个 Key 不影响另一个。
- 重启设置存储后仍能解密。
- 其他 Windows 用户无法直接解密（适配器层测试可注入 fake protector）。
- 测试连接失败返回可读错误。
- 前端弹窗不把 Key 写入 localStorage。
- 视频区域保持禁用状态。
